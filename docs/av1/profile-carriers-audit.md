# Carriers audit: the amended profile-carriers result, checked independently

*2026-11-05. An independent audit of `## Profile carriers, measured (amended)` in
[`profile-carriers.md`](profile-carriers.md) (commit `43a3511f`), against its pre-registered protocol (§D there).
It did not run the browser; it read the committed rows and re-ran the arithmetic. What the auditor computed is*
derived*; what it could not check is* unverified*.*

1. **Audited:** the collector's verdict, that the layered AV1 stream "stays a candidate" on `dbts_a1`, `dbts_b1` and
   `dbts_c1`. It was checked against the four shards' 68 244 committed rows and against the protocol's rule.
2. **Found:** the rule was applied as written, and every cell re-derived by hand matches. But on every volume the
   answer was fixed by bytes before any time was measured. On `dbts_c1` the one time-won cell (`lay-k16`, high view)
   is about as large as a quality-matching asymmetry that favours it.
3. **Rests on:** the shards' rows and indexes, the pin, `amended.py` and its tests, re-run here. There is a second
   implementation of the values, the A/A gate and the pairs, written for this audit from the protocol's text alone
   (it is not committed).
4. **Left:** how decode time scales with stream bytes at a fixed G (it would size finding 2). Whether each layered
   unit's `_1` (middle) bytes are a byte prefix of its `_2` (top) unit, which the exact-ask bytes assume, is
   *unverified*.
5. **Bottom line:** the verdict **stands with caveats**.

**Terms, first use.** A **block** is one fresh browser running, in one round on one volume, one layered configuration
(`lay-kk`, keyframe interval k), the separate one at the same group length (`sep-gG`), and two runs of the HTJ2K
control (`ctrl`, and the **A/A** `ctrl-aa`). The **A/A gate** reads a block only if the 95 % interval of the median
of log(`ctrl-aa` ÷ `ctrl`) contains 0. Times are in **HTJ2K-frame units**: an arm's time ÷ its block's control's
median frame decode in that round. A configuration is **dominated** if a rival has no more bytes, no time decided
against the rival, and fewer bytes or a time decided for it. It is **on the frontier** if nothing dominates it and
no cheaper rival's comparison is gated out (then it is **not read**). The **pin**
(`results/amended-content.json`) holds the quantizers chosen to match each role's target quality, *in-window PSNR*
(PSNR over the samples the display window shows). The **timed stream** is the coded stream nearest the target. Its
**bytes at the target** are interpolated between the two quantizers that bracket the target.
