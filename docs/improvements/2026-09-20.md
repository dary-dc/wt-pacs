`--blackout-after` and N2's `--blackout-again-after-ms` had each rewritten the same warm-up loop.
Both are kept and they compose — the repeat is now scheduled from wherever the first blackout
fires, so at both defaults the harness does exactly what N2 measured. `server/src/transport/tuning.rs`,
`server/src/main.rs` and `../transport/transport-conclusions.md` §3 merged without one, and carry
both sides.

**One lab fragility, not fixed here.** `lab/scripts/blink_cells.sh` ends a cell with a
`ZeroDivisionError` when an arm collects no path counters at all, which a low round count makes
likely — the fill still measures, only the report dies. It is the script's own, not the merge's.
