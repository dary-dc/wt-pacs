## 3 · What cost time in this container

* **`wasm-opt` from apt (v108) builds a WASM bundle that fails at init** (`Table.grow`). wasm-pack's
  own download fails here; fetch binaryen `version_117` from its GitHub release with `curl` and put
  its `wasm-opt` first on `PATH`.
* **Chromium**: the global playwright wants a newer build than `/opt/pw-browsers` holds; set
  `CHROME_PATH=/opt/pw-browsers/chromium`.
* **One `CARGO_TARGET_DIR` per worktree.** Shared across worktrees at different commits, a release
  build linked a stale `frame-envelope` and the gate failed on code that was fine.
* **`server_ab.sh` ignores `CARGO_TARGET_DIR`** (it reads `$ROOT/target/release`), and a `LOGDIR`
  you pass must already exist.
* **`check_equivalence.sh --local`** needs `/usr/sbin` on `PATH`, `server/scripts/gen_dev_cert.sh`
  run first, and a tree nginx's worker can read: the scratchpad under `/tmp/claude-0` is `0700`.
* **docker** is installed but its daemon is not running: start `dockerd` first.
* The gate takes ~5 minutes from a cold target, of which the conformance step idles ~54 s.
