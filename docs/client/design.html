The safety report

Decided by the owner on 2026-11-14, not built. Does: reports an exactness failure: always on, never sampled, not gated by the telemetry rate; no pixels and no patient data; the load report's endpoint and record format. On a mismatch the second decode first, then the frame blocked, the reader told in that frame's view and the report sent at once (exactness in production; frame integrity).

two series of one source

The server serves the optimal-quality series and its exact series; the pairing refuses two of different sources.

the want, ordered

The controller tells the store what is wanted, in order; the store decides from where.

want {ordered misses} · ack

Only the store talks to the downloader. The want stays ordered down to the wire. A frame changes owner at the ack: the downloader owns what is owed, the store what is held.

dispatch, under credits

At most K frames are dispatched and unacked, so a full store reaches the wire as a pause (the view worker's design).

frame {SharedArrayBuffer, exact}

The decoded samples, written once into shared memory, with the check's result.

the frame to paint

Paint first, then the cache write; the store never decides a paint. VOI is part of paint.

cache write and read

Behind the lab's ?writer=; no write runs on the view worker's thread. Only frames checked true; each re-checked on read.

asks and runs, frames on the wire

Over the downloader's WebTransport session. Open: the delivery comparison.

the Lossless request

An explicit request from the reader for the frame on screen. Open: an automatic exact request at narrow windows (what the label may claim).

the exact frame

Checked against its ingest digest, held beside the store, painted with ✓ Lossless only if checked true.

The delivery comparison (open)

A
the optimal-quality view only (a measurement arm)
B
HTJ2K lossless only (served in any case; also an arm)
C1
the approach: the fill, then an exact frame on request
C2
the fill, then the whole exact series, measured, not summed

Theory: fill ≈ max(bytes × 8 ÷ bandwidth, frames × decode per frame ÷ decoders) + rest; A and C1 win where the link binds and lose their margin where decode binds. None run; the protocol is not written (design.md §Open, the delivery comparison).
