## 2. The 220-level view, in plain words

On a phone, a hardware decoder gives the page a colour picture, and the page cannot switch that colour conversion
off (S, `hw-inverted.md` §1). An 8-bit video picture in *studio range* uses only the codes 16 to 235 for black to
white (H.273, S). That is 220 grey levels, about 7.8 bits. If the stored grey stays inside 16–235, every code
survives the conversion one to one. The page can then turn the colour back into the grey code and check each frame
against the ingest's digest (T; 219 or 220 levels survived in every model).

The series itself has 1 024 levels (10 bits) or 4 096 (12 bits). One of the 220 levels covers about 4.7 or 18.6 of
the series' units (D). This shows up on narrow windows. The cost is 1.16–2.49x today's bytes (M). In practice the
picture needs headroom (~200 levels), because luma leaves 16–235 on every frame (M, cell I4). None of this has been
run on a phone.
