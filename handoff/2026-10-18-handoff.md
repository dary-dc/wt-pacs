## 5. How to work

**Cloud routines** (`RemoteTrigger`): environment `env_01JYTE3P4vcDau65CyvoLc55`, model `claude-opus-5-5`, tools
Bash/Read/Write/Edit/Glob/Grep, source `https://github.com/dary-dc/wt-pacs`. `create` with the brief as the event's
message, then `run`. A brief carries: read `CLAUDE.md`; the branch (new from unified, or the PR branch); the identity
and no-trailer rule; push only that branch, never merge or open PRs; the task with file:line; the proof (test first,
mutate, interleave timed arms); the checks (the full `scripts/gate.sh` builds in the cloud: `rustup target add
wasm32-unknown-unknown`, `cargo install wasm-pack --version 0.15.0 --locked`, `client/transport/wasm/build.sh`,
`fetch_openjph.sh`, `fetch_xxh3.sh`, `dockerd` for the decoder build, playwright under `npm root -g`); the report.
Results come back through `list_runs` and `get_run_log`; a log can be cut off at its end, so verify on the branch.

**GitHub from the local machine:** no `gh`. The PAT in the git credential store works for push and the REST/GraphQL API
(restored 2026-10-17). `handoff/tools/`:
- `pr_edit.py N` — edit a PR body: stdin is a JSON list of `[old, new]` pairs (`""` old appends); strips footers.
- `pr_merge.py N SHA "title"` — mark ready and merge with method `merge`, pinned to `SHA`. Only on "merge #N".
- `ci_wait.py SHA...` — polls the check runs (authenticated) until all three are complete, then prints them.

The decision table is edited without a worktree: read the file from the branch, edit it, then
`GIT_INDEX_FILE=<tmp> git read-tree origin/claude/project-thread-9uugfm`, `git update-index --cacheinfo`,
`git commit-tree`, `git push origin <commit>:refs/heads/claude/project-thread-9uugfm`.
