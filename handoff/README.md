# Handoff files

Copies of the Claude Project's shared `handoff/` and `review/` files, for an orchestrator that cannot read that
folder. Start with [`2026-10-18-handoff.md`](2026-10-18-handoff.md); [`2026-10-17-handoff.md`](2026-10-17-handoff.md) is history and holds the rules' long form. `tools/` has the orchestrator's GitHub helpers (no `gh` needed). In it, `review/2026-10-16.md` is
[`review-2026-10-16.md`](review-2026-10-16.md) here and `review/2026-10-16-pr104.md` is
[`review-2026-10-16-pr104.md`](review-2026-10-16-pr104.md). `kit.tar.gz` and the 2026-10-15 transcript are not
copied; `prep.sh` and the repo's scripts rebuild the kit. This branch is never merged.
